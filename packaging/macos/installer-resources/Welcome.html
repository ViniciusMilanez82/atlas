Instalar o Atlas

Este instalador coloca o aplicativo na pasta Aplicativos do Mac. Você não precisa instalar Python, Docker ou usar o Terminal.

Requisitos: Mac com chip Apple Silicon (linha M) e macOS 15 ou posterior. Esta edição não funciona em Mac Intel. O instalador verifica os requisitos antes de copiar o aplicativo.

Feche o Atlas caso ele já esteja aberto. Clique em Continuar, confira as informações e escolha Instalar. O macOS pode pedir a senha de um administrador para gravar na pasta Aplicativos.

Versão Alpha de desenvolvimento — não é a V1 completa.
O instalador não acrescenta funções que ainda faltam no Atlas. O pacote não possui Developer ID nem notarização da Apple. Use somente dados fictícios e não o trate como funcionário autônomo pronto para produção.

A instalação é offline, não cria contas, não cobra serviços e não altera as proteções do Mac.
